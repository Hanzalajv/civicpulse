Network Isolation Proof

Purpose:
Demonstrate that the frontend container cannot reach PostgreSQL.

Docker networks:
- edge: frontend <-> backend
- internal: backend <-> postgres <-> redis (internal: true)

The frontend joins edge only. Postgres joins internal only. The two networks are not connected.

Command:
docker compose -f compose.yaml exec frontend ping -c 1 postgres

Output:
ping: bad address 'postgres'

Interpretation:
The frontend container has no DNS record for postgres because it is not on the same Docker network. The command fails as expected.
